# AfyaBora — Local Dev Server

This folder contains a minimal Node/Express scaffold to preview the EJS views.

Quick start

1. Install dependencies

```bash
cd stitch_afyabora_health_management_system
npm install
```

2. Run

```bash
npm start
```

Open http://localhost:3000/login

Notes

- This is a simple scaffold for local preview only. No database is configured.
